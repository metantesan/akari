# Contributing

Thanks for helping improve Akari. Issues and pull requests are welcome.

## Before opening a pull request

- Describe the user-visible problem or improvement.
- Keep changes focused and update documentation when behavior changes.
- Run `cargo fmt --all -- --check` and `cargo check --workspace --all-targets`.
- Add or update tests for behavior changes and run `cargo test --workspace`.
- Include the operating system and steps to reproduce platform-specific issues.

Akari is experimental. Platform support claims should distinguish successful
builds from runtime testing on an actual device or desktop.

Please follow the expectations in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
